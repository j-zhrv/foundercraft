# FounderCraft для ChatGPT Work

Обучение делам основателя по [карте FounderCraft](https://foundercraft.ai-era.ru/): понять смысл, попробовать самостоятельно, разобрать результат. Плагин помогает голосом или текстом, читает карточки и первоисточники через WebMCP открытого сайта.

Здесь одна общая версия для владельца и всех пользователей. Это публичный GitHub marketplace, доступный по адресу репозитория; отдельного одобрения в общем каталоге OpenAI он не означает. Проект независим от OpenAI и Y Combinator.

Файл LICENSE пока отсутствует: отдельная лицензия ещё не выбрана. Репозиторий не заявляется как юридически оформленный лицензированный open-source проект.

## Что нужно

- Актуальный ChatGPT Desktop с доступом к **Work**, плагинам и встроенному браузеру с WebMCP. Доступность зависит от аккаунта, версии приложения и настроек организации.
- Подключённый компьютер, на котором выполняется Work. Команды установки запускайте **на этом же компьютере и под тем же пользователем**, чей локальный профиль использует Desktop.
- Codex CLI с командами `codex plugin marketplace add` и `codex plugin add` (проверьте `codex plugin --help`). Для проверки этого релиза использован runtime Desktop 0.164.0.
- Интернет для GitHub и FounderCraft. Для разговора голосом — доступный ChatGPT Voice и микрофон; их включает сам пользователь. Текстовый режим работает без микрофона.

Плагину не нужны API-ключи, отдельный MCP-сервер, Bun или подписка на собственный сервер FounderCraft. Лимиты Work и Voice определяет OpenAI.

## Установка и первый разговор

### Проще: поручите установку своему ChatGPT

Вставьте в ChatGPT Desktop Work:

> Установи AI-учителя FounderCraft из https://github.com/j-zhrv/foundercraft по INSTALL.md в локальный профиль моего ChatGPT Desktop. После установки помоги выбрать подходящий набор и объясни, с чего начать. Если нужен новый Work-чат с плагином, дай готовое задание для переноса. Не запускай обучение без моего согласия.

Если набор уже выбран на сайте, используйте задание со страницы подключения: оно содержит публичный ID и сохраняет выбор. [Инструкция для устанавливающего помощника](INSTALL.md) объясняет проверки и перенос в новый чат. Данные другого браузера автоматически не переносятся.

### Вручную

1. В терминале на компьютере Desktop добавьте marketplace и установите пакет:

   ```sh
   codex plugin marketplace add j-zhrv/foundercraft --ref main
   codex plugin add foundercraft@foundercraft
   ```

2. Откройте **Plugins**, выберите источник **FounderCraft** и проверьте установленный плагин. Если каталог ещё не появился, перезапустите Desktop. Создайте **новый Work-чат** и выберите FounderCraft через меню плагинов или `@`.
3. Напишите: «Помоги начать обучение FounderCraft под мою ситуацию». Помощник откроет вводную либо ситуационную статью, затем подходящий оффер. Начните выбранный набор явным действием на оффере. Можно сначала обсудить подход или читать самостоятельно.
4. Для голоса выберите **Start voice chat** / **Start new voice chat** в Desktop и сами разрешите микрофон. Если кнопки нет, обновите приложение и проверьте доступность Voice для аккаунта и организации; продолжайте текстом.

В дальнейшем: «Продолжи мою сессию FounderCraft». Сохранённое место сайта используется без повторного старта. Открытие карточки не считается её прочтением, объяснение с подсказкой — самостоятельным результатом, а проверка знаний остаётся добровольной.

Если раньше был установлен личный плагин, сначала проверьте новый пакет в отдельном Work-чате, выбрав именно **foundercraft@foundercraft**. Затем можете удалить прежний через интерфейс плагинов. Не выбирайте обе версии в одном учебном чате.

## Обновление и удаление

```sh
codex plugin marketplace upgrade foundercraft
codex plugin add foundercraft@foundercraft
codex plugin list --marketplace foundercraft --json
```

Marketplace обновляется из `main`; повторная установка обновляет установленную копию. После обновления откройте новый Work-чат; при необходимости перезапустите Desktop. Мгновенная замена инструкций в уже активных чатах не гарантируется. Не редактируйте установленный кеш: изменения поддерживаются в этом репозитории.

Для удаления пакета и затем, при желании, источника:

```sh
codex plugin remove foundercraft@foundercraft
codex plugin marketplace remove foundercraft
```

Удаление плагина не удаляет разговоры ChatGPT, файлы с вашими итогами или локальные данные сайта; ими управляйте отдельно.
