# Подключить AI-учителя FounderCraft

Эта инструкция предназначена для ChatGPT Work или другого помощника, которому пользователь поручил установить FounderCraft. Используйте существующий marketplace `foundercraft` из `j-zhrv/foundercraft`, пакет `foundercraft@foundercraft`. Не создавайте второй marketplace или личную копию плагина.

## Сначала сохраните выбор пользователя

Если в задании есть название, публичный ID набора или ссылка FounderCraft, сохраните их в разговоре. Не начинайте новый подбор вместо уже выбранного набора. Выбор набора не является согласием начать учебную сессию.

Устанавливайте на компьютере и в локальном профиле, которые использует ChatGPT Desktop пользователя. Установка в облачную песочницу или другой профиль не устанавливает плагин в его Desktop. Если нужная среда недоступна, сообщите это, не имитируя успех. Не просматривайте чужие профили, личные переписки или секреты ради установки.

## Установите и проверьте

1. Используйте доступный официальный runtime с командами `codex plugin`. Если этих команд нет, назовите отсутствующую возможность и предложите проверить актуальность Desktop/его runtime. Не редактируйте `config.toml` вручную и не запускайте сторонние bootstrap-скрипты.
2. Сначала проверьте настроенные marketplace и установленный пакет. Если FounderCraft уже установлен, включён и соответствует текущей версии репозитория, повторная установка не нужна. Перейдите к активации учителя. Иначе добавьте наш GitHub-marketplace и установите пакет:

   ```sh
   codex plugin marketplace add j-zhrv/foundercraft --ref main
   codex plugin add foundercraft@foundercraft --json
   codex plugin list --marketplace foundercraft --json
   ```

   Если marketplace уже настроен именно на этот репозиторий, используйте `codex plugin marketplace upgrade foundercraft`, затем установку/обновление пакета. Если имя занято другим источником, не заменяйте его молча. Соблюдайте подтверждения установки, которые требует среда.
3. Проверьте возвращённые `installed`, `enabled`, `version`, имя пакета и marketplace. Ожидаемую версию берите из текущего манифеста этого репозитория. Ошибка или отсутствие подтверждения не являются установленным плагином. Повторная установка не должна создавать другую запись.

Пакету не нужны API-ключи, внешний MCP-сервер или отдельный платный сервис FounderCraft. Он не включает микрофон и не меняет настройки голосового режима.

## Передайте разговор учителю

Установленный пакет и доступный в текущем чате плагин — разные состояния. Если хост не подхватил FounderCraft в текущий разговор, предложите **новый Work-чат**, выбор FounderCraft через меню плагинов или `@` и дайте готовое задание для вставки. При необходимости пользователь перезапускает Desktop. Не утверждайте, что новые инструкции уже активны, только по наличию файлов в кеше.

Передайте без изменений выбранный публичный ID и ссылку пользователя. Пример для выбранного набора:

> Используй FounderCraft. Я уже выбрал набор «название» (ID из моего задания). Открой переданную страницу подготовки во встроенном браузере ChatGPT, затем этот набор. Не подбирай другой без моей просьбы. Объясни ближайший учебный шаг и дождись моего согласия начать. Можно начать текстом; голос я включу сам.

Если набора ещё нет: «Используй FounderCraft. Помоги понять мою ситуацию, выбрать один подходящий набор и объясни его пользу. Перед началом обучения дождись моего согласия».

Это шаблоны, не повод выдумывать название, ID, выбранную цель или историю пользователя. Не переносите личный прогресс из другого браузера догадками. После активации следуйте справочникам плагина.

Для голоса пользователь сам выбирает **Start voice chat** / **Start new voice chat** и разрешает микрофон. Доступность Work, плагинов, встроенного браузера и голоса зависит от аккаунта и версии ChatGPT. Если голос недоступен, предложите тот же сценарий текстом.
