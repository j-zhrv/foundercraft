# 0.3.3

- Уточнён приоритет уже выбранного режима над повторным прохождением входной воронки.
- Краткая специализация набора отделена от актуальной личной очереди и состояния WebMCP.
- Удалено основание требовать весь корпус до урока: текущая карточка, обзор и чтение по вопросу.
- Добавлен контракт интеграции локальных голосовых режимов и разбор 39 v3-промптов. Живой голосовой A/B-тест не проведён.

# Изменения

## 0.3.2 · 2026-10-29

- Самостоятельный разговорный вход в видимой вкладке без дополнительных агентов и повторного оффера.
- Семантическая подготовка и существующий start_learning согласованы с одним согласием пользователя; личные копии и место сохраняются.
- Явно разобраны строковый JSON, смена регистрации после навигации и восстановление при неизвестном результате.
- Проверки исходников не являются живым голосовым прогоном; он для этой версии пока не подтверждён.

## 0.3.1 · Подготовка выбранного набора

- Промпт из оффера ведёт к странице подготовки выбранного набора, а не обратно к подключению.
- Учитель сохраняет выбор, ждёт согласия и использует видимое действие перехода в приложение.
- Учтено новое название самостоятельного входа; установка и голос в реальном Desktop для этой версии ещё не проверены.

## 0.3.0 · 2026-10-27

- Добавлена короткая установка через поручение помощнику и отдельная INSTALL.md для существующего GitHub-marketplace.
- Два сценария: выбрать набор вместе с учителем или сохранить уже выбранный на сайте набор при переходе в Work.
- Различены установка, активация плагина в новом чате и явное согласие начать обучение.
- Уточнён реальный первый вход через видимую кнопку оффера, а не прямую навигацию в приложение.
- Голос остаётся добровольным действием пользователя; тот же путь работает текстом. Методика карточек, проверки знаний и личные данные не изменены.

## 0.2.1 — 2026-10-26

- Исправлена категория OpenAI interface: `Education & Research` в portable и совместимом манифестах. Метка каталога согласована отдельно по строковому контракту marketplace.
- Проверка категории использует допустимые названия OpenAI; добавлен регрессионный тест прежнего недопустимого `Education` и независимая проверка типа категории marketplace.
- Runtime smoke test теперь проверяет ожидаемые версию и категорию, чтобы не принять установленный старый релиз за обновлённый.
- Методика и сайт не менялись.

## 0.2.0 — 2026-10-26

- Перенос существующего FounderCraft 0.1.22 в один публичный пакет и GitHub marketplace.
- Удаление личных обращений и контактных данных; общие правила для каждого пользователя.
- Первый вход через статью и явное действие на оффере; сохранение прежней сессии при продолжении.
- Сохранение полного чтения первоисточников, добровольной проверки и различия самостоятельной попытки и помощи.
- Личные итоги только по поручению, вне кеша и публичного репозитория; без обещания записи всего голоса.
- Инструкции Work/Voice, обновления и удаления, проверка пакета, ссылок и типовых персональных данных.
